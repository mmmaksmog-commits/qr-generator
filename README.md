# 🔳 QR

**Генератор QR-кодов для ссылки, текста, Wi-Fi и визитки.**

### ▶️ [Открыть](https://mysik-portfolio.vercel.app/qr-generator/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- Четыре типа: ссылка, текст, Wi-Fi (с подключением в одно касание) и vCard
- Свои цвета, пресеты, три формы точек
- Уровень коррекции ошибок и проверка контраста
- Скачивание PNG 1024×1024 и векторного SVG
- Поддержка кириллицы и эмодзи (UTF-8)

## Стек

JavaScript, Canvas, SVG, qrcode-generator. Без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/qr-generator.git
cd qr-generator
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.
